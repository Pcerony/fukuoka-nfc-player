# 福冈之声：NFC 唱机网页试版

独立仓库、独立 HTTPS 网址。原展览网站、数据库和管理流程不改动。

## 体验

Android Chrome 打开后显示唱机和「启用 NFC」按钮。工作人员授权后保持页面在前台；展览卡碰一下播一段，播放中再碰立即切换，播完就停。唱片只在实际播放时转动。不提供歌单、录音或管理入口。

展览卡写入一条 NDEF 文本记录，内容为 `fukuoka-voice-player:v1`，仅作为触发标记，不是密钥，也不含录音编号或网址。忽略不匹配的标签；目标设备上验证持续贴卡不重复触发、移开重碰可以触发。未格式化空卡不在网页试版范围内。

## 音频与异常

使用现有 `public-map` 目录，仅从公开录音随机选取；有多段时避开上一段。播放前调用 `public-playback-url` 重新授权，不保存签名链接或音频，不使用后台凭据。新触碰使未完成的旧播放请求失效。授权、网络或播放失败时停止并显示简短状态，恢复后可重试。

## 验收

自动化验证标签筛选、随机换段、过期请求和播完停止。真实 HTTPS 预览用 Android Chrome、标记卡和普通卡验收：初次授权后无需再点屏幕，普通卡无反应，贴住不连跳，移开重碰换段。浏览器模拟不代替实体卡验收。
